ClipFlow Manager

A desktop application for Windows that helps a creator prepare vertical video clips and send them as drafts to their own TikTok inbox.

Terms of ServicePrivacy Policy

What it does

  • Imports short vertical clips from a folder on the creator's own computer.
  • Lets the creator review the title and hashtags, and checks the video before anything is sent.
  • Connects the creator's own TikTok account with TikTok Login Kit and shows which account is connected.
  • Uploads the selected video to the creator's TikTok inbox as a draft using the TikTok Content Posting API. With the permissions it requests (user.info.basic and video.upload) the application cannot publish: the creator opens the TikTok notification, reviews the draft and publishes it in the TikTok app.
  • Asks for an explicit written confirmation for every video it sends, and keeps a local record to help avoid sending the same clip twice from this application.

TikTok data and permissions

In this TikTok integration the app only requests the permissions it needs: user.info.basic (to show which account is connected) and video.upload (to send a draft to the creator's inbox). Authorization tokens are stored only on the creator's own computer, encrypted with Windows. Details are in the Privacy Policy.

Status

This is a desktop tool developed and used by its author. It runs on the user's computer and does not operate any server.
