Privacy Policy

Application: ClipFlow Manager   Operator: Nahuel Cassoli   Effective date: 2026-10-11

1. How the application works

The application is software that runs on the user's own Windows computer. The operator does not run any server for it (the application only opens a temporary listener on the user's own computer to receive TikTok's authorization response), does not receive the user's data, and the application contains no analytics, advertising or tracking.

2. Information handled when a TikTok account is connected

  • The TikTok open_id and display name of the account that authorized the application (permission user.info.basic), read after authorization and again whenever the user asks the application to verify the connected account; used only to show which account is connected and to check that the authorization belongs to that account.
  • The OAuth access token and refresh token issued by TikTok, the list of permissions granted, and their expiry dates.
  • The app credentials (client key and client secret) that the user enters from their own TikTok developer account.

The application also keeps a local history of the videos the user prepares and sends: title, description and hashtags, the path of the video file on the user's computer, the status, the identifier TikTok returns and a log of events. Its purpose is to show the status and to avoid sending the same clip twice from this application. It stays on the computer.

The application does not request or store the user's TikTok password, followers, messages, videos already published, or any other profile data.

3. Videos

The application sends only video files that the user selects on their own computer, and only after the user confirms each one in the application. The file is transferred directly from the user's computer to TikTok through the official TikTok Content Posting API (video.upload, as a draft in the user's TikTok inbox). It is not copied to any server of the operator.

4. Where the information is stored and how it is protected

The information the application itself keeps is stored only on the user's computer; what is sent to TikTok (the authorization data and the video the user chooses to send) is processed by TikTok under its own terms and privacy policy. Authorization tokens and app credentials are encrypted with Windows data protection (DPAPI), so that only the same Windows user account on that computer can read them.

5. Sharing

The operator does not sell, rent or share the information. The only recipient of data sent by the application is TikTok, when the user connects their account or asks the application to send a draft.

6. Retention, revoking access and deletion

  • Inside the application, the option "Revoke and delete" asks TikTok to revoke the authorization and deletes the stored tokens and credentials from the computer.
  • The user can also remove the application's access from the TikTok app settings at any time.
  • "Revoke and delete" (shown as "Revocar y borrar" in the Spanish interface) does not erase the local history of sent videos described above; deleting the application's data folder does.
  • Deleting the application's data folder on the user's computer removes the information the application stores there. Videos already sent to TikTok remain in the user's TikTok account and can be removed there; revoking the authorization in the TikTok settings is a separate step.
